# Ignition Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** Build the local engine-sound companion to Syrinx, for combustion and sci-fi sound design.
**Architecture:** Shared deterministic DSP supplies live AudioWorklet output and worker-rendered WAV files. A standard-library Python launcher serves the static app on loopback and opens Chrome.
**Tech Stack:** ES modules, Web Audio, HTML/CSS, Python 3.12, Node's built-in test runner; existing Playwright for QA only.
**Spec:** `docs/superpowers/specs/2026-11-06-ignition.md`

## Constraints and review focus
- No runtime dependencies or network media; do not alter Syrinx.
- 48 kHz, 24-bit, mono WAV exports; 2–30 second bounds.
- Untrusted patches: validate finite values, field names, enums, version, size.
- Rapid ignition/stop and render interactions must not leak contexts/workers or leave controls locked.
- Held-rev release must work on blur, pointer cancellation, and keyboard focus loss.
- Low/high RPM and extreme layer mixes remain finite and bounded.
- Narrow screens keep transport and exports reachable.
